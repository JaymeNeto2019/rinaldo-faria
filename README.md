# Rinaldo Faria

Site institucional responsivo, em português, feito com HTML, CSS e JavaScript, sem dependências externas.

## Visualizar

Abra `index.html` em um navegador ou publique a raiz do repositório no GitHub Pages. Os arquivos da pasta `assets` devem permanecer ao lado dos arquivos do site.

## Contato

O canal de contato público é o Instagram: https://www.instagram.com/drrinaldofaria/.
